# Feature specifications

These specs describe the remaining parity work for the standalone Tauri/Svelte app. They are intentionally implementation-oriented: each names the behavior, the likely integration point, and the target UI.

They target Codex desktop parity. Full ChatGPT conversation history, account billing, and consumer-chat features remain outside this app's current scope.
